⚙ Google Drive Setup (one-time):
1. Go to console.cloud.google.com → Create/select a project
2. Enable Google Drive API
3. OAuth consent screen → External → Add scope: drive.appdata
4. Credentials → OAuth 2.0 Client ID → Web Application → Add your domain to Authorized JS origins
5. Copy the Client ID and replace the placeholder in the script: client_id: 'YOUR_ID.apps.googleusercontent.com'
6. Data is saved in Drive's hidden appDataFolder (private to your app, not visible in My Drive)
